# Hub
1. Crea un repository su GitHub e carica tutto il contenuto di questa cartella nella radice (branch `main`).
2. Su GitHub: Settings → Pages → Source "Deploy from a branch" → `main` / `(root)` → Save.
3. Dopo un paio di minuti apri con **Safari** su iPhone l'indirizzo `https://<utente>.github.io/<repository>/`.
4. Tocca Condividi → "Aggiungi alla schermata Home": da lì l'app si apre a tutto schermo e funziona offline.
5. Apri Palestra → "Importa scheda" → scegli il file HTML del PT → controlla l'anteprima → "Conferma".
6. I dati restano solo sul telefono: ogni tanto usa Hub → "Esporta backup" e conserva il file JSON.
7. Per pubblicare un aggiornamento cambia il numero in `version.js` e ricarica i file.
8. Il timer di recupero suona solo ad app aperta, a schermo acceso e con la suoneria non silenziata.
